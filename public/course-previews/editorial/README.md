# Mandarin Lab course preview imagery

All five assets were generated specifically for this project with OpenAI's built-in image generation tool, then exported as optimized JPEG files. They are original generated assets rather than third-party stock photography, so no Unsplash, Pexels, Pixabay, or other stock license/attribution applies.

## Shared production prompt

Photorealistic-natural editorial course-preview photography in a portrait 4:5 composition; modern Chinese or Shanghai context; subtle cinematic realism; slightly cool/neutral palette; restrained red accents; reduced saturation; rich blacks; realistic materials; no logos, watermark, poster graphics, presentation styling, clipart, giant typography, or neon oversaturation.

## Course prompts and crops

- `beginner-study.jpg` — modern Shanghai study desk with an open notebook, simple handwritten Chinese characters, pinyin notes, pen and pencil. Object position: `50% 54%`.
- `hsk-preparation.jpg` — structured beginner-to-intermediate Chinese exam preparation desk with reading workbook, practice sheets, vocabulary notebook, pen and muted highlighter; no prominent level-number text. Object position: `50% 57%`.
- `business-shanghai-office.jpg` — sophisticated glass meeting room above Shanghai at blue hour, skyline, meeting table, closed laptop and notebook; no posed people. Object position: `52% 48%`.
- `travel-shanghai-metro.jpg` — contemporary Shanghai metro platform with train, wayfinding and distant commuters; practical urban travel rather than tourism imagery. Object position: `48% 45%`.
- `kids-learning-desk.jpg` — clean modern learning desk with notebook, muted colored pencils, simple Chinese character cards and wooden study tools; no cartoons or mascots. Object position: `50% 55%`.

Source dimensions: `1120 × 1400` pixels for every image. Display treatment uses `object-fit: cover`, a 4:5 wrapper, and shared CSS color grading.
